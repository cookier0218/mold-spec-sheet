# 模具調校規格表 ｜ 惟家 JustPlus

射出成型用的線上「模具調校規格表」。同仁可直接在瀏覽器填寫、自動儲存、下載 PDF。
純靜態網頁，無後端，部署在 GitHub Pages。

## 功能

- **線上填寫**：產品資訊、機台規格、加工條件（射出/保壓設定、塑料溫度、模溫/冷卻）全欄位可編輯，當空白範本重複使用。
- **自動儲存**：邊填邊存，重新整理或關閉後再開都還在（存在瀏覽器 localStorage）。
- **多筆命名規格表**：可為不同模具各建一份、重新命名、複製、刪除。
- **匯出 / 匯入**：匯出成 `.json` 檔，傳給同仁或在另一台電腦匯入（localStorage 是單機單瀏覽器，跨人/跨機靠匯出檔）。
- **下載 PDF**：按「下載 PDF」或 Ctrl/Cmd+P，選「儲存為 PDF」。版面已針對 A4 列印優化。

## 資料存在哪？

- 全部存在**你自己的瀏覽器**（localStorage），**不會上傳**到任何伺服器，repo 裡也不會有任何填寫內容。
- 換電腦 / 換瀏覽器不會自動同步 → 用「匯出 / 匯入」搬資料。
- 清除瀏覽器資料會一併清掉 → 重要規格表記得先匯出備份。

## 本機預覽

```bash
cd mold-spec-sheet
python3 -m http.server 8080
# 瀏覽器開 http://localhost:8080
```

| `index.html` | 表單結構（表格重現規格表版面） |

| `app.js` | 自動儲存、多筆管理、匯出入、PDF |
| `.nojekyll` | 關閉 Jekyll，確保靜態檔原樣提供 |
